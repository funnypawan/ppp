# Dream Classes

A responsive student-dashboard prototype for **Dream Classes**, an Indian learning platform for school and competitive-exam students. The demo is built with plain HTML, CSS and JavaScript, so it runs without a build step or third-party runtime dependencies.

## Run locally

From the repository root, start a static server:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Then open `http://localhost:4173`.

## What’s in the prototype

- Student dashboard with class schedule, learning progress, streak and course continuation.
- Course catalog, live-class schedule, study resources, DPP/test flow, doubt submission, peer community and progress views.
- Local interactions for DPP questions and scoring, course details, class reminders, material bookmarks/offline-list state, community upvotes/posts, doubt history, notification preferences and dark mode.
- Responsive desktop, tablet and mobile layouts; no API keys or external service connections are required.

Sample student and course data are illustrative. Authentication, real video/live classrooms, payments, file storage, push notifications and persistent backend data are not connected in this frontend prototype.
