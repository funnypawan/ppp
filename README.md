## 🚌 Indian Bus Simulator 3D

A complete 3D bus driving game for Android, built in this repository.

* **Playable Android build** — `indian-bus-simulator/` (Three.js/WebGL + Capacitor, appId `in.indianbus3d.game`)
  * 8 original Indian buses, 7 Indian maps, heavy-vehicle physics, traffic AI, passengers
  * Career mode (10 missions / 9 categories), free drive, garage, customisation, economy, daily rewards
  * Weather (sunny → snow) and a day/night cycle, HUD with minimap + GPS, six cameras, touch controls
  * APK: <https://github.com/funnypawan/ppp/releases/tag/bus-sim-apk>
* **Unity 2022.3 LTS source project** — `unity/IndianBusSimulator/` (modular C#, scene based, type-checked in CI)
