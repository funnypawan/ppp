# 📋 PRODUCTION TIPS

| Tip | Detail |
|---|---|
| ⏱️ **Pacing** | Har image par 10-11 sec. Quote cards par 6-8 sec + slow zoom. End screen par 20 sec hold. |
| 🎥 **Motion** | CapCut/Premiere me har image ko "Zoom In 105→115%" ya "Pan Left→Right"ken Burns effect do — static boring lagta hai |
| 🔤 **Hindi Text** | AI se Devanagari mat banwao — Canva/CapCut me Montserrat/Poppins Hindi (Jost, Mukta) fonts use karo |
| 👤 **Consistency** | Character Sheet wali description har prompt me same rakhna, ya --cref use karo |
| 🎨 **Color Coding** | Poor = gray/blue tones, Rich = golden tones — poore video me follow karo (script ki storytelling strong ho jayegi) |
| 🔁 **Reuse** | Kuch hero images (jaise Image 4, 33, 38) ko transitions me dobara use kar sakte ho |
| 🛠️ **Tools** | Midjourney (best quality), Bing Image Creator (free), Leonardo.ai (free credits), Ideogram (free, text accha banata hai) |
